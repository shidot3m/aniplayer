# Agent Instructions

## Mandatory Pre-Task Rule
Before starting ANY task, the AI agent MUST:
1. **Inspect Available Skills:** Review active skills (in `.agents/skills/` and system builtin skills). Read the relevant `SKILL.md` before proceeding with design, frontend, backend, or review tasks.
2. **Inspect & Use MCP Tools:** When relevant MCP tools are configured (e.g. `shadcn`, `context7`, `playwright`, `chrome-devtools`), leverage them directly instead of guessing or hand-rolling boilerplate.

# Живой прогон #68 — токены «Ночной кинозал»

Ветка `feat/night-cinema-tokens`, коммит этого прогона. Ворота: `bun run check` — typecheck, Biome,
Vitest (26 файлов, 117 тестов), `bunx aislop ci` → **Healthy, 100/100**. Сборка: `bun run build`
проходит, в собранном CSS роли на месте (`--color-ground:#101010`, `--color-glass-line:#f5f5f529`,
`--duration-hover:.16s`, `--ease-out:cubic-bezier(.23,1,.32,1)`).

Приложение запускалось настоящим, не браузером: `bun run dev` (Vite 8.3.5 на `127.0.0.1:1420`) и
`src-tauri/target/debug/aniplayer.exe` — dev-сборка грузит dev-сервер, а Rust-слой в этом тикете не
менялся, поэтому перекомпиляция не требовалась. Окно 1296x839. Управление и захваты —
`../60/win32.ps1` (`click`, `key`, `move`, `shot`) и `maximize.ps1` этого каталога.

## Измеренные значения (Chromium, живой DOM)

`getComputedStyle` с открытого каталога:

```
--color-ground #101010   --color-surface-1 #1a1a1a  --color-surface-2 #232323
--color-ink #f5f5f5      --color-ink-2 #a6a6a6      --color-ink-3 #6e6e6e

--ease-out cubic-bezier(0.23, 1, 0.32, 1)
--duration-hover 160ms   --default-transition-duration 160ms
--default-transition-timing-function cubic-bezier(0.23, 1, 0.32, 1)
body background = rgb(16, 16, 16)
граница карточки = rgba(245, 245, 245, 0.08)
```

Обход всех элементов страницы на шесть цветов старой палитры (`rgb(225, 29, 72)` — былый rose-600,
`rgb(9, 10, 15)` — старый ground, `rgb(190, 18, 60)`, `rgb(251, 113, 133)`, `rgb(226, 232, 240)`,
`rgb(148, 163, 184)`) по `color`, `backgroundColor`, `borderTopColor`, `outlineColor`:
**0 попаданий**. Экраны сменили палитру все разом, потому что `--color-*: initial` выключает
заводские линейки Tailwind — класс `bg-rose-600` больше не генерирует ничего, и розовое не могло
пережить миграцию незаметно.

## Оговорка про `04-settings-webview2.png`

В кадре диалога настроек слева видны два белых «серпа». Это не интерфейс: `CopyFromScreen` по
rect'у окна WebView2 срывает часть слоя, когда под диалогом работает `backdrop-filter`. Тот же DOM,
снятый вторым рендерером (`05-settings-chromium.png`), чист; в кадре без диалога (`03`, `06`)
артефакта нет. Проверено намеренно, потому что «экран выглядит сломанно» — это ровно тот случай,
где нельзя отмахнуться от скриншота.

## Открытые границы, которые закрывают не здесь

- `--color-glass`, `--blur-glass`, `--duration-screen-in`, `--duration-screen-out` есть в исходнике
  и в статическом тесте, но ещё не попадают в собранный CSS: Tailwind выдаёт только использованные
  переменные, а потребителей этих четырёх заведут #71 (переходы экранов) и #72 (стекло поверх кадра).
- Карточки всё ещё пишут `transition-all duration-300` — хартия движения требует 160 мс и именованных
  свойств. Это работа #69 (hover карточки) и #72 (контролы плеера мгновенно); здесь изменён только
  слой токенов, поэтому кривая у этих переходов уже хартийная, а длительность — ещё своя.
- Стекло как класс (`bg-glass backdrop-blur-glass border-glass-line`) собирается в #72.
